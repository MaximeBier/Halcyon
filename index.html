Why an analog overlay?

Classic overlays show a key as on or off; yours is analog, so show what it can actually do.
Halcyon is the simplest and most complete way to do it: fully styleable, nothing to install.

Pressure, not just clicks

Each key fills with press depth and switches color at actuation. The stream shows half-presses, feathering, releases: everything an on/off overlay misses.

Questions

The short answers. The full guide has the long ones.

Does anything leave my PC?+

No. Your keystrokes, layouts and OBS password stay in your browser and travel only to your own OBS on your local network. There is no account, no server-side storage, no analytics. Two people using the site at once can't see each other's keys.

Which keyboards are supported?+

Every Wooting keyboard with analog switches (60HE, 80HE, Two HE and variants). Other analog brands (Razer, SteelSeries, Keychron, DrunkDeer…) use their own protocols and aren't supported yet. Want yours next? Open an issue on GitHub.

Why Chrome or Edge only?+

Reading key travel needs WebHID, which only Chromium browsers implement. Any Chromium-based browser works; Firefox and Safari don't. The overlay itself runs in OBS's own browser, so this only concerns the setup page.

Is my OBS password safe in the URL?+

It never leaves your machine, but it is visible in the browser source properties. Keep OBS's properties window and the capture page off stream, like any settings screen.

Will it cost me frames in game?+

The overlay is an SVG in a browser source, redrawn only when a key moves. It's in the same league as a chat widget. The capture page can stay minimized once your keys are placed.

Does it work with Streamlabs or other software?+

OBS Studio 30+ only for now: Halcyon talks to OBS through its built-in WebSocket server. The overlay page can also be opened in any browser window if you want to record it another way.

Is it really free?+

Yes. No premium tier, no watermark. The source is public on GitHub under the PolyForm Shield licence: you can read it, modify it and host your own copy, as long as you don't use it to build a competing product.
